# Team Photos

Place team member photos here with the following naming convention:

## Leadership
- president.jpg
- vice-president.jpg

## Branch Directors
- queens-director.jpg
- brooklyn-director.jpg
- manhattan-director.jpg
- staten-island-director.jpg

## Instructions

1. Add your photos to this folder using the naming convention above
2. Update the team data in `/app/about/team/page.tsx`:
   - Update names in the `leadership` object
   - Update bios for each person
   - Update `branchDirectors` object with actual names and bios
   - Update the `tutors` array with all tutor names

Supported formats: .jpg, .jpeg, .png, .webp

Recommended dimensions: Square aspect ratio (e.g., 800x800px) for consistency
