# Summer 2025 Gallery Images

Place your photo files here with the following naming convention:

- photo-1.jpg
- photo-2.jpg
- photo-3.jpg
- etc.

Supported formats: .jpg, .jpeg, .png, .webp

## Instructions

1. Add your photos to this folder
2. Update the `photos` array in `/app/gallery/summer-2025/page.tsx` with:
   - Correct file paths
   - Meaningful alt text for accessibility
   - Captions describing each photo

## Privacy

Remember: All photos should have proper consent as outlined in our disclaimer policy.
